# 📜 《輪迴世界》開發規格書 - 03_UIUX: 賽博戰術全息 UI/UX 升級規範 (Tactical HUD Design)

本文件定義遊戲戰鬥介面（`battle_screen`）的視覺美學、版面佈局（Layout）、資訊層級（Information Hierarchy）與互動體驗（UX Feedback）。

---

## 1. 視覺風格定義 (Visual Aesthetic & Palette)

* **設計風格：** 賽博朋克戰術全息 HUD（Tactical Hologram UI）。採用深色暗黑基底（Deep Charcoal `#0D1117`）搭配半透明玻璃擬態面板（Glassmorphism with Blur），減少視覺雜亂感。
* **色彩語意對照表 (Color Semantics):**
  * **藍色 / 霓虹青 (`#00FFFF`):** 我方單位、預設科技 UI、防禦與 AP 顯示。
  * **紅色 / 警示緋紅 (`#FF3366`):** 敵方單位、受傷、高危險威脅、環境扣血。
  * **金黃 / 基因鎖金色 (`#FFCC00`):** 基因鎖爆發、暴擊傷害、高階技能、經驗值。
  * **紫色 / 虛空紫 (`#9933FF`):** 靈體單位、詛咒/精神傷害、MISS 閃避。
  * **綠色 / 生化綠 (`#00FF66`):** 治療、護盾、疫苗 Buff。

## 2. 戰鬥畫面版面配置 (Screen Layout Architecture)

畫面分為 5 個核心模組區塊，採用 16:9 黃金比例分割，確保戰場中央的攻防動畫不被遮擋：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [頂部列] 戰場距離 (100m) │ 戰場環境 (高溫毒氣) │ 速度行動順序條 (SPD Order)   │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                       【戰場中央 2D/3D 動畫區】                         │
│             [敵方前/後排單位]            [我方前/後排 6 人隊伍]         │
│                                                                        │
├───────────────────────────────┬────────────────────────────────────────┤
│ [左下] 戰鬥歷程日誌 (Combat Log) │ [右下] 戰術行動操控盤 (Action Panel)   │
│  (支援半透明捲動與動態高亮)     │  (當前角色頭像/HP/MP/AP + 6 大指令環)   │
└───────────────────────────────┴────────────────────────────────────────┘
2.1 各區塊 UX 優化細節
1. 頂部速度行動順序條 (Speed & Action Order Bar)
舊版問題： 文字呈現順序過於抽象。

UX 升級： 採用「滑動頭像佇列（Timeline Ribbon）」。角色頭像由左至右排列，邊框顏色標示敵我（藍框我方，紅框敵方）。當輪到該單位行動時，頭像放大並發出金黃色呼吸燈光效。

2. 頂部環境與距離抬頭顯示 (Environment & Distance Banner)
視覺呈現： 簡約全息膠囊標籤。

距離標籤： 顯示 [ 📍 距敵：100m (遠距離) ]，點擊可查看距離懲罰細節。

環境標籤： 顯示 [ ☣️ 高溫毒氣: -5% HP/回合 ]，帶有微微脈動紅光警示。

3. 左下戰鬥歷程日誌 (Scrollable Terminal Log)
視覺呈現： 模擬黑客終端機（Hacker Terminal），採用半透明黑色背景。

UX 升級： 預設僅顯示最新 2 條核心紀錄（簡化畫面）。點擊右側 [ 📜 全文 ] 按鈕或向上滾動，才展開完整的歷程視窗，不遮擋戰鬥視線。

4. 右下戰術行動操控盤 (Tactical Command Wheel)
視覺呈現： 圓弧半包覆式輪盤 UI，緊貼螢幕右下角，符合人類右手操作習慣。

面板資訊包含：

當前行動者資訊卡： 頭像 + 動態血條/魔條 + 4 個巨大全息 AP 水晶粒（剩餘 AP 一目了然）。

核心指令按鈕群：

⚔️ 普通攻擊 (3 AP)

🔥 專屬技能 (4 AP)

🎯 精準瞄準 (1 AP)

🛡️ 防禦 (1 AP)

🎒 戰術背包 (1 AP)

🧬 基因鎖爆發 (1 AP - 動態金光閃爍)

3. 互動回饋與防呆視覺 (Interactive UX Feedback)
3.1 嚴格防呆與按鈕狀態
AP 不足置灰： 當剩餘 AP 為 1 時，消耗 3 AP 的『普通攻擊』與 4 AP 的『專屬技能』按鈕會變為半透明灰色（Opacity 30%），並顯示亮紅色 (AP不足) 標籤，無法點擊。

階級壓制警示 (Power Tier Warning): 當普通人角色選擇用普通槍械攻擊 Tier 2 以上怪物時，目標怪物品頭頂會浮現黃色警示標記 [ ⚠️ 高階甲殼: 預計彈彈 80% ]，提示玩家切換武器或開啟基因鎖。

3.2 戰鬥打擊感與飄字 (Damage Floating Text)
普通傷害： 白色數字向上飄逸並淡出。

暴擊傷害 (Critical): 金黃色特大字體，伴隨螢幕輕微震動（Screen Shake）。

階級壓制 / 跳彈： 灰色字體 跳彈 (Deflect) 或 力量壓制 (Immune)。

MISS / 閃避： 紫色斜體 MISS (距離過遠)。
