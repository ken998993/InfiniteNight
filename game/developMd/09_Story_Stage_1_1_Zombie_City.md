# 📜 《輪迴世界》開發規格書 - 09: 第一關劇情與教學流程 (1_1_Zombie_City)

本文件定義第一副本「喪屍末日世界（極光重工遺址）」的主線劇情腳本 (`zombie_city.rpy`)、團隊人員死亡退場機制、兩波戰鬥教學與專屬 AI 視覺提示詞。

---

## 1. 團隊開局陣容與人員存活歷程 (Party Status Flow)

* **開局人員（共 7 人）：** 
  * 1 個資深者：資深執行者「冷月」。
  * 6 個新人：主角 (顧臨淵)、白領青年「項天」、心靈感應少女「蘇曉」、刺青流氓「趙虎」、驚慌青年「周揚」、發福大叔「錢富貴」。

* **死亡與退場淘汰鏈：**
  1. **趙虎 (刺青流氓) — 擅自離隊死：** 不信邪撞開密封閥門，觸發「超音波奈米防禦」被瞬間分解成黏液（警告玩家不可違規）。
  2. **周揚 (驚慌青年) — 第一波戰鬥死：** 戰鬥中因恐慌擅離陣型，被第 1 波敏捷型喪屍 (agile_zombie) 撲倒咬死（展示前後排保護陣型的重要性）。
  3. **錢富貴 (慢吞吞大叔) — 毒氣關門死：** 第 2 波戰鬥清場後，安全門發出閉合倒數，錢富貴體能不足被困在門外，遭毒氣與閘門雙重壓毀。
  4. **最終存活人數 (4 人)：** **資深者 (冷月) + 主角 (顧臨淵) + 2 個生還新人 (項天 & 蘇曉)**，四人一同回歸輪迴廣場大廳。

## 2. Ren'Py 主線劇情腳本範例 (`zombie_city.rpy`)

```renpy
label stage_1_1_zombie_city:
    scene bg_aurora_lab_entrance with fade
    
    # -------------------------------------------------------------
    # 1. 醒來與開局陣容介紹 (1 資深者 + 6 新人)
    # -------------------------------------------------------------
    show portrait_lengyue_f at left
    lengyue "醒了就站起來。算上主角，這次一共來了 6 個新手。想活命就閉嘴聽我說。"
    
    show portrait_rogue_m at right
    rogue_m "什麼新手？老子是幫會老大，少拿這種科幻電影威脅我！這地方門都沒鎖，我走人！"
    
    # -------------------------------------------------------------
    # 💀 死亡事件 1：新人 A (刺青流氓) 衝出去觸發防禦死亡
    # -------------------------------------------------------------
    "刺青流氓無視冷月的警告，猛地撞開前方印有『極光重工 - 警告生物危害』的密封閥門。"
    play sound "nanotech_buzz.wav"
    "【極光重工 - 生物安全防禦系統啟動】"
    "空氣中發出刺耳的高頻震動，流氓整個人在兩秒內被超音波分解成一灘透明黏液。"
    
    lengyue "第一個白痴死了。不想變成黏液，就跟緊我。"
    
    # 3. 企業清理隊登場與發放防禦服
    show portrait_aurora_captain at right
    aurora_captain "掃討隊注意，發現殘留試驗品！不想被當成廢料處理，就穿上這些『tactical_hazmat_armor 戰術服』幫我們開路！"
    
    # 觸發 UI 教學：穿上防護服
    call screen tutorial_equip_window(item_id="tactical_hazmat_armor")
    
    # -------------------------------------------------------------
    # ⚔️ 【第一波戰鬥】：基礎近戰與陣型教學 (死亡事件 2)
    # -------------------------------------------------------------
    "前方安全門破裂，第一波敏捷型喪屍 (agile_zombie) 爬了出來！"
    
    # 💀 死亡事件 2：新人 B (周揚) 被敏捷型喪屍咬死
    "其中一名驚慌的新人周揚嚇得掉頭就跑，離開了坦克的防禦範圍！"
    "【一隻敏捷型喪屍從陰影中撲出，瞬間咬斷了他的喉嚨！】"
    
    aurora_captain "白痴！離開前排保護就是這個下場！全體進入戰鬥姿態！"
    
    # 呼叫第一波戰鬥（3 隻敏捷型喪屍，數據自 monsters_db.json 讀取）
    call battle_start(stage_id="1-1_WAVE_1")
    
    "【第一波戰鬥結束，清空敵人】"
    
    # -------------------------------------------------------------
    # 💣 【第二波戰鬥】：毒氣環境 + 手雷教學 (死亡事件 3)
    # -------------------------------------------------------------
    scene bg_aurora_corridor with flash
    play sound "gas_leak.wav"
    
    "眾人衝進狹長走廊，兩側的毒氣管線突然爆裂！"
    "【警告：高溫毒性氣體洩漏！每回合扣除 5% HP，3 回合內未消滅敵人將全隊窒息！】"
    
    aurora_captain "怪群擋住了通路！接住『high_explosive 高爆破片手雷』，炸平牠們！"
    
    # 發放手雷道具並開啟手雷使用教學提示
    $ player_inventory.add("high_explosive", count=2)
    show tutorial_popup_grenade "【戰術教學】請點擊『物品』選擇『high_explosive 高爆破片手雷』對怪群進行範圍清場！"
    
    # 呼叫第二波戰鬥（5 隻密集怪群 + 3 回合毒氣限時）
    call battle_start(stage_id="1-1_WAVE_2_GAS")
    
    "【第二波戰鬥結束，怪群被炸平！】"
    
    # 💀 死亡事件 3：新人 C (慢吞吞大叔) 被安全門擋住死亡
    "【警告：生物隔離安全門即將於 5 秒內永久關閉！】"
    lengyue "快衝過去！門要關了！"
    
    "眾人奮力撲過安全門，但動作慢吞吞的大叔卡在了最後方。"
    "【轟隆！厚重的合金防爆門重重落下！】"
    "門後傳來大叔絕望的敲門聲與高溫毒氣噴發的慘叫聲，隨後歸於寂靜……"
    
    "冷月冷冷地掃視殘存的隊伍：『6 個新人死了 3 個，現在只剩下你們 3 個了。』"
    
    # -------------------------------------------------------------
    # 🧠 6. 底層生物神經網絡 A.D.A.M. 與智者備份 (下載 adamcore.jpg)
    # -------------------------------------------------------------
    scene bg_aurora_core with fade
    "殘存的 4 人（冷月 + 主角 + 2 新人）踏入極光重工最深處的生物神經網絡機房。"
    
    if player_party.max_int >= 100:
        menu:
            "【智者檢定】隊伍智力 >= 100，發動思維入侵並撕裂 A.D.A.M. 核心原始碼":
                show adamcore at item_show_center with dissolve
                $ player_inventory.add("ITEM_HIVE_AI_BACKUP")
                "【智者成功剝離神經核心！獲得『亞當神經元矩陣備份 (A.D.A.M. Core)』，可帶回房間安裝高科技合成台。】"
                hide adamcore with dissolve
            "遵從極光重工隊長命令，炸毀神經主機":
                pass
    else:
        "隊伍智力不足，無法承受神經網絡的反噬，只能由清理隊將主機炸毀。"
        
    # -------------------------------------------------------------
    # 🌌 7. 回歸輪迴空間廣場 & 冷月新手導引
    # -------------------------------------------------------------
    "【任務完成！傳送光柱降臨，全體生還隊員回歸輪迴空間廣場！】"
    "冷月站在巨大的主神光球前，向生還新人詳細解說輪迴空間規則："
    "1. 10 天休整期與抹殺生存機制"
    "2. 個人房間意識具現化創造與 A.D.A.M. 3D 打印安裝"
    "3. 點數與命運碎片（D~S階）血統/裝備兌換商城"
    "4. 輪迴全身修復 (消耗 100 點數全面治癒致命傷殘)"
    
    $ player_progress.completed_main_stages["STAGE_1_1"] = True
    jump main_room_exploration
